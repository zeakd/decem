# Changelog

## 0.1.0

First release. The API is not frozen and may change before 1.0.

Published from a laptop and without a provenance attestation, which is the one release
that will be. A trusted publisher cannot be configured for a package that does not exist,
so this version creates the registry entry; every version after it is published by the
workflow in this repository, from a tag, with an attestation and no token.
